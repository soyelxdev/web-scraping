🌐 Web Scraping – Ultimate Developer Collection

A collection of open-source web scraping tools, data extraction frameworks, APIs, browser automation tools, and developer resources.

🚀 About

Welcome to Web Scraping Collection!

This repository brings together useful open-source projects for web scraping, data extraction, automation, API development, media processing, and web technologies.

The goal is to provide developers with a single place to explore different tools, learn new technologies, and build powerful applications.

📦 Projects Included

- HaiKei – Developer resources and tools.
- Information Extraction Chinese – Information extraction project.
- Rettiwt API – Twitter/X API integration.
- Scrapling – Web scraping framework.
- Anime Website – Anime website project.
- Apify MCP Server – Web scraping and automation integration.
- Consumet API – Media content API.
- Exa MCP Server – Search and MCP integration.
- Ferret – Web data extraction project.
- Live Streaming on AWS – Cloud streaming resources.
- Obscura – Open-source project.
- OTT Packager – OTT media packaging.
- Scrapy – Python web scraping framework.
- Web Scraper Chrome Extension – Browser-based scraping tool.

📥 Installation

Clone this repository:

git clone https://github.com/sks584845-arch/web-scraping.git

Navigate to the directory:

cd web-scraping

Extract the ZIP archives of the projects you want to use.

Follow the original documentation of each project for installation and setup.

💻 Usage

1. Explore the available project archives.
2. Select your desired project.
3. Extract the project files.
4. Install the required dependencies.
5. Follow the original setup instructions.
6. Start building!
